# Character Editor - Facial Animation EyePatch

A RimWorld mod that fixes eye color saving, loading, and UI editing issues when using [Character Editor](https://steamcommunity.com/sharedfiles/filedetails/?id=1874644848) together with [[NL] Facial Animation - WIP](https://steamcommunity.com/sharedfiles/filedetails/?id=1635901197).

### Features
- **Preserves Eye Colors on Load**: Fixed an issue where loading a saved character preset reverted eye colors to random colors.
- **Fixes White Eye Glitch in UI**: Fixed a bug where setting Eye Color 2 (right eye) caused Eye Color 1 (left eye) to turn blank/white. Both eyes can now be set in any order.

### Requirements
- Harmony
- [Character Editor](https://steamcommunity.com/sharedfiles/filedetails/?id=1874644848)
- [[NL] Facial Animation - WIP](https://steamcommunity.com/sharedfiles/filedetails/?id=1635901197)

---

Character Editor と [NL] Facial Animation を併用した際のアイカラー（目の色）に関する不具合を修正するパッチMODです。

### 主な修正内容
- **プリセット読み込み時の目の色を復元**: 保存したキャラクターをロードした際、目の色がランダムな色で上書きされてしまう問題を修正。
- **白目化バグの解消**: アイカラー2（右目）を設定・変更した際にアイカラー1（左目）が白目（透明）になってしまうバグを修正。

### 前提MOD
